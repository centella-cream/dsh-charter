# dsh-charter 0.3.2

> **Status:** Development candidate — accessibility/evidence gates pending.
> **Version scope:** `0.3.2`
> **Baseline:** 2026-11-16
> **Authority:** [version roadmap](../design/version-roadmap.zh.md); [verification](../verification.md) for evidence.
> **Supersedes / Superseded by:** none / none.

`0.3.2` is the accessibility/evidence convergence patch after `0.3.1`. It does not change record schema, Remote
wire, prompt projection, or the model tool surface.

## Scope

- Root-text graph scaling: the graph canvas scales as a unit when the root font exceeds 16px, capped at 200%,
  with a scrollable viewport instead of new text clipping.
- Final-build evidence for empty/staged/applied/conflict-confirmation, forced-colors, reduced-motion, breakpoints,
  and root-font measurements.
- Documentation/governance reconciliation: GUI Appendix D, dependency-graph status, verification current status,
  roadmap and docs-index pending wording.
- Eleven-version compatibility matrix including DSH `0.2.2-rc.3`.

## Still-open manual gates

- Real VoiceOver/NVDA walkthrough of tabs, Change Set sheet, graph keyboard semantics, meter/live region.
- Native Desktop window/ABI matrix; automated renderer screenshots are not a substitute.
- Human sign-off on the frozen mockup side-by-side review.
