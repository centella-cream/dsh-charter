# Release notes

The latest published release is [0.1.0-rc.6](0.1.0-rc.6.md). [0.2.0](0.2.0.md) is the current development candidate
(not published); [0.1.0-rc.5](0.1.0-rc.5.md) is the previous accepted release.

Published release history is summarized in [CHANGELOG.md](../../CHANGELOG.md) and remains available through the
immutable Git tags and GitHub Releases. Older per-release note files were removed during the rc.5 documentation
cleanup so the docs tree describes the current line rather than carrying multiple process drafts.

For installation, compatibility, recovery behavior, and known limitations, start from the
[user guide](../user-guide.md), [compatibility matrix](../design/compatibility.md), and
[verification record](../verification.md).
