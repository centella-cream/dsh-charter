# dsh-charter 0.3.3

> **Status:** Release candidate — implemented and exercised locally, awaiting the release workflow.
> **Version scope:** `0.3.3`
> **Baseline:** 2026-11-23; latest published release `0.3.2` (SHA-256 `9dcb82ae…`).
> **Authority:** [version roadmap](../design/version-roadmap.zh.md); [extraction design](../design/charter-draft-extraction-v1.zh.md); [verification](../verification.md).

`0.3.3` improves the review-only compaction draft. It does not change the record schema, prompt projection,
`charter_read`/`charter_propose`, or the model write boundary.

## Scope

- Semantic extraction: sentence-boundary-only splitting, oversized candidates kept whole and marked, explicit
  truncation metadata.
- Duplicate folding: exact and conservative prefix duplicates become one representative with fold count and refs.
- Compatibility: thirteen declared DSH versions, including the current `0.2.2-rc.4`/`0.2.2-rc.5` releases; the local source matrix passes all thirteen.
- Automatic language following: when the draft language differs from the DSH UI locale (`zh`/`en`), the source
  draft renders first and the Host performs bounded strict-JSON translation in the background. Slow/custom models
  are split/retried per batch, partial successes are retained, and failures fall back to source text with a
  visible notice; an optional dedicated provider/model can be configured.
- Additive `charter/bootstrapDraft` and structured `applyBootstrap` refs; legacy extraction/apply remains unchanged.

## Known limits

- Translation requires a configured session model; without one the draft remains in the source language and the
  Pane shows a fallback notice. Set `languageFollow: false` in the profile config to disable the automatic call;
  deterministic extraction/folding still applies.
- Only sentence-level semantic splitting is deterministic; semantic aggregation/diff review remains future work.
- Large drafts translate in bounded batches with per-batch timeouts, one split retry, and partial merge; one slow/failed batch does not discard successful translations.
- An optional `languageFollowProvider`/`languageFollowModel` pair lets custom-API users send normalization to a known-fast model instead of the session default.
- The draft card renders the source-language extraction immediately; language normalization runs in a background request and replaces the draft only while it is pristine. `languageFollowTimeoutMs` bounds that background wait (default 60s).
- Not published yet. Root `SHA256SUMS` continues to describe the published `0.3.2` artifact.
