> **Status:** Development candidate — implemented; pending release acceptance.

> **Baseline:** 2026-11-03
> **Authority:** [version roadmap](../design/version-roadmap.md); [verification](../verification.md) for evidence.

`0.2.0` is the workspace and proposal-review upgrade. It is currently a development candidate on
`feat/0.2.0-workspace`; no tag, GitHub Release, or npm publication exists yet.

## Status

- Package version: `0.2.0`.
- Versioning rule: starting at `0.2.0`, releases use plain increments (`0.2.0`, `0.2.1`, ...) and never an
  `rc` suffix.
- Source acceptance: strict TypeScript, build/smoke, 35 files / 405 tests, and the eight-version DSH
  compatibility matrix pass on the current tree.
- Release acceptance still requires the real browser/Desktop A/B, real-model compaction, performance, and
  remaining manual gates recorded in [verification](../verification.md).

## Added

- Three primary areas: Workspace, Review Center, and Diagnostics & Maintenance.
- Deliverable `requires` dependencies with canonical graph validation, derived readiness states, stable
  `D<n>` prompt keys, and an editable prerequisite selector.
- Record schema v2 with in-memory v1 migration, proposal batches with typed provenance, and item
  `proposalBatchId` / `reviewedAtRevision` metadata.
- Objective proposals with initialize/redirect acceptance rules, required replacement reasons, reject,
  and purge tombstones.
- Proposal batch, objective proposal, item, and bounded recent-change queries, plus `summary` and
  `watchSummary` Remote projections.
- Pending-only `charter_propose` agent tool; the model still cannot accept, reject, archive, restore, purge,
  edit, or change progress.
- Change Set before/after summary and digest in the edit result.
