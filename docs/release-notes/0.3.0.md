# dsh-charter 0.3.0

> **Status:** Released 2026-11-13 — npm `latest`/`next` and GitHub Release `v0.3.0` published.
> **Version scope:** `0.3.0`
> **Baseline:** 2026-11-13
> **Authority:** [version roadmap](../design/version-roadmap.md); [verification](../verification.md) for evidence.
> **Supersedes / Superseded by:** none / none.

`0.3.0` is the document-feel GUI release. It replaces the previous Pane's stacked-card presentation with one
readable contract document across Workspace, Review Center, and Diagnostics & Maintenance, while keeping the
record schema, Host tools, Remote wire, and prompt projection compatible with `0.2.2`.

## Added

- **Underline area tabs** replace the left vertical navigation at every width.
- **Document column + Change Set rail**: a 720px reading column, with a 280px quiet Change Set margin note on
  wide screens and the existing modal sheet on narrow screens.
- **Document rows**: objective lead, invariant/deliverable rows, aligned D-number/byte metadata, quiet row
  actions, 36px dashed empty rows, a three-row skeleton, and a single inline notice.
- **Change Set rail**: title/count, prompt/item delta, grouped operation rows, quiet unstage links, and one
  closing hint.
- **Execution-path graph**: disclosure summary with state-aware action label, fixed 184px nodes, three-layer
  anatomy, candidate/staged/active edge language, static legend, and a compact inspector.
- **Version chip**: the Pane header keeps the approved `v0.3.0` version identifier beside revision and prompt
  meter.
- **Host tool fix**: `charter_read standing` exposes stable deliverable ids so `charter_propose.requires` can
  reference real deliverables; `D<n>` labels are documented as display-only.

## Changed

- Workspace, Review Center, and Diagnostics now share the same document typography, spacing, row, chip, notice,
  empty-state, and focus contracts.
- The Change Set sheet and rail share one content anatomy.
- Client CSS is upserted by its owned `data-plugin-css` style tag, so a hot-reloaded bundle replaces stale CSS
  without duplicating style tags.
- The Pane adds `diagnostics` as an explicit top-level route so the Diagnostics tab lands at the top rather
  than a context-preview anchor.
