# dsh-charter 0.1.0-rc.4

`0.1.0-rc.4` is a compatibility-only patch for DSH `0.2.1-rc.3` and `0.2.1-rc.4`.

## Artifact

- `dsh-charter-0.1.0-rc.4.tgz`, SHA-256 `40a9e195d9e4d20861edbe07adce9c53ea685fc3deabee0d1aab0e98af11b70d`

## Why this release exists

`0.1.0-rc.3` declared exactly five DSH versions and therefore correctly refused to install on DSH `0.2.1-rc.3`:
the Desktop compatibility gate reported the exact five-version `engines.dsh` / peer range. The plugin API was
re-verified against the complete `0.2.1-rc.3` and `0.2.1-rc.4` package graphs; no plugin code change was required.

## Compatibility

- `engines.dsh` and every `@deepseek-ai/dsh-*` peer range now include the seven verified versions:
  `0.1.7-rc.2 || 0.2.0-rc.1 || 0.2.0-rc.2 || 0.2.1-rc.1 || 0.2.1-rc.2 || 0.2.1-rc.3 || 0.2.1-rc.4`.
- DSH `0.2.1-rc.4` is the primary development baseline; DSH `0.2.1-rc.3` is covered by the same full matrix.
- On both new versions: typecheck passes, the Host ESM build and client bundle pass, and the full suite is
  25 test files / 331 tests. The five older versions remain unchanged and verified.

## Upgrade

Existing `0.1.0-rc.3` records are read without migration; `recordSchemaVersion` and the `dsh_charter_v1` domain are
unchanged. Install the new exact version in a Desktop or Web profile:

```bash
dsh plugin --profile web add dsh-charter@0.1.0-rc.4
```

For Desktop, install `0.1.0-rc.4` from npm or the GitHub Release tarball. DSH `0.2.1-rc.3` and `0.2.1-rc.4` are
both accepted; older declared versions are unchanged.

## Verification

- `npm test` / `npm run check`: 25 files / 331 tests pass on DSH `0.2.1-rc.4`.
- Full DSH matrix: `0.1.7-rc.2`, `0.2.0-rc.1`, `0.2.0-rc.2`, `0.2.1-rc.1`, `0.2.1-rc.2`, `0.2.1-rc.3`,
  `0.2.1-rc.4` — typecheck, build, Vitest 331/331, remote/client smoke.
- Normal, exact-artifact, and packed recovery smokes pass on the final tarball.
- Public CI runs the committed gates on Node 22.19.0 and Node 24.

This release adds no domain capability and no new recovery features. The broader `0.1.0-rc.4` product review scope
is not part of this compatibility patch; this release only unblocks installation on current DSH 0.2.1 RC builds.
