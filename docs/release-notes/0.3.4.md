# dsh-charter 0.3.4

> **Status:** Development candidate — v7 single-call implementation exists locally, but the v8 adaptive-batched design is **not implemented**; not release-ready. Manual/A-B acceptance is still required.
> **Version scope:** `0.3.4` — opt-in draft calibration patch on top of the published `0.3.3`.
> **Baseline:** 2026-11-24; latest published release `0.3.3` (SHA-256 `707043d3…`).
> **Authority:** [version roadmap](../design/version-roadmap.zh.md); [calibration design](../design/charter-draft-calibration-v1.zh.md); [verification](../verification.md).

`0.3.4` adds an opt-in model calibration layer to the review-only draft. It does not change the record
schema, standing prompt projection, or the model tool surface.

## Scope

- Current v7 candidate performs one calibration call for all draft candidates; the v8 design (see the calibration design doc §5) replaces this with adaptive batches + capped concurrency + split retry + Host-side merge. v8 is **not implemented yet**.
- Semantic aggregation and readable rewriting in the requested `zh`/`en` language.
- `c-*` calibration candidates with `mergedFrom` provenance and an additive `applyBootstrap` extension.
- Trusted Host-only evidence attachment for calibrated items; no evidence field is exposed on the wire.
- Capability/status method, consent gate, bounded in-memory cache and run id.

## Known limits

- Calibration is disabled by default. It requires `calibration.enabled: true` and a matching
  `calibration.consentVersion`; it sends compaction draft text to the configured model.
- The plugin detail page exports localized English/Chinese metadata whose description names the
  current `0.3.4` development candidate; the README is refreshed with current Pane and graph screenshots.
- No 0.4.0 readiness/execution-memory/relation capabilities are included.
- Local exact-artifact gates pass: package smoke, packed recovery, fresh DSH 0.2.2-rc.5 Web profile, and Gateway acceptance on DSH 0.2.1-rc.3/rc.4.
- The calibration A/B protocols and real-model manual acceptance remain open release gates. A real 10-turn Web test showed the v7 default fails with `max-tokens` and only calibrates 12 candidates; v8 must fix and rerun it before release.
- Review hardening restores language-follow fallback, gates calibration to zh/en, binds runs to source handles, wires mergedFrom excerpts into the review diff, validates explicit effort when adapter metadata is available, and covers actual 0.3.2/0.3.3 record fixtures plus calibration gate/cache/TTL/capability/failure tests. Cancellation relay and the per-ref suppressed selection set remain documented post-MVP items.
