# dsh-charter 0.3.4

> **Status:** Development candidate — implemented locally; not published. Manual/A-B acceptance is still required.
> **Version scope:** `0.3.4` — opt-in draft calibration patch on top of the published `0.3.3`.
> **Baseline:** 2026-11-24; latest published release `0.3.3` (SHA-256 `707043d3…`).
> **Authority:** [version roadmap](../design/version-roadmap.zh.md); [calibration design](../design/charter-draft-calibration-v1.zh.md); [verification](../verification.md).

`0.3.4` adds an opt-in model calibration layer to the review-only draft. It does not change the record
schema, standing prompt projection, or the model tool surface.

## Scope

- Strict one-shot calibration of `dsh-charter` draft candidates through the optional Host `ctx.llm` service.
- Semantic aggregation and readable rewriting in the requested `zh`/`en` language.
- `c-*` calibration candidates with `mergedFrom` provenance and an additive `applyBootstrap` extension.
- Trusted Host-only evidence attachment for calibrated items; no evidence field is exposed on the wire.
- Capability/status method, consent gate, bounded in-memory cache and run id.

## Known limits

- Calibration is disabled by default. It requires `calibration.enabled: true` and a matching
  `calibration.consentVersion`; it sends compaction draft text to the configured model.
- No 0.4.0 readiness/execution-memory/relation capabilities are included.
- The calibration A/B protocols and real-model manual acceptance remain open release gates.
