# dsh-charter 0.1.0-rc.6

`0.1.0-rc.6` was withdrawn before formal acceptance. Its npm version is deprecated, its GitHub release/tag were removed, and it must not be used through channels.

## Status

- Withdrawn version: `0.1.0-rc.6` (npm deprecated; no GitHub tag/release).
- No product runtime code path, record schema, Remote method, model tool, or domain change is included yet; the model-facing `charter_read` description was shortened.
- `0.1.0-rc.5` remains finalized and immutable; its npm publication is deferred.
- `0.1.0-rc.5` is the latest published release; rc.6 remains source-only and deprecated on npm.

## Added

- DSH `0.2.1-rc.5` compatibility: engines, every DSH peer range, `dsh.compatibility.dshReleases`, the tracked eight-version matrix, and its frozen lockfile. The existing Web/Desktop client entry needs no API change.
- A `?` help affordance on every navigation section; hover/focus shows a one-sentence description.
- Context preview now offers Formatted JSON and Exact text modes. Formatted JSON is pretty-printed; exact bytes
  remain available for verification.

## Observability

- Added a read-only traffic checker for model attempts, active/historical/epoch snapshots, section churn,
  duplicate bytes, tool-schema bytes, token usage, and redundant `charter_read` candidates.
- Shortened the `charter_read` tool description; the standing charter is normally already in runtime context.

## Documentation changes

- README and user guide describe the real channel state: published rc.5, withdrawn rc.6, and the historical rc.4 release.
- Release, verification, compatibility, version-roadmap, and changelog text were consolidated around that state.
- Old pre-tag instructions and stale install examples were removed.
- The Charter header version badge is retained from rc.5; the rc.6 client constant is synchronized with
  `package.json` by the drift test.

## Verification

This version is withdrawn. The published rc.5 artifact remains the supported release; see [releasing](../releasing.md)
for the recovery state.
