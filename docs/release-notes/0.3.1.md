# dsh-charter 0.3.1

> **Status:** Development candidate — local acceptance pending.
> **Version scope:** `0.3.1`
> **Baseline:** 2026-11-13
> **Authority:** [version roadmap](../design/version-roadmap.zh.md); [verification](../verification.md) for evidence.
> **Supersedes / Superseded by:** none / none.

`0.3.1` is the GUI convergence patch after `0.3.0`. It closes the dependency-graph audit and standing-envelope
observability gaps without changing the record schema, Remote wire, or prompt projection.

## Scope

- Graph lane headings and directional arrows; a path-wide 44px edge hit target using `non-scaling-stroke`;
  distinct history line style; adaptive canvas height; removal of the unused graph `ops` input.
- Diagnostics standing-envelope estimate with exact item serialization, 32 KiB cap, `maxPromptBytes`, id
  overhead, and `<80%` / `>=80%` / over-cap states.
- Local `traffic-check` parses the real JSON `{ok, message}` tool envelope for proposal rejection classification,
  including non-requires failures; active-surface hashes; `traffic-diff`
  before/after baseline comparison. No runtime telemetry or upload.
- Updated frozen graph mockup/spec and README screenshots.

## Not in 0.3.1

- `requires.propose` for existing deliverables, record schema v3, and `charter.diagnostics` → 0.4.0.
- Any prompt byte change, including `dependencyAware`.
- Upload/telemetry collection.

## Verification

- `npm run check`: 41 files / **499 tests** PASS; ten declared DSH versions remain matrix-verified.
- Browser audit: lane headings, SVG arrows, a 44px edge hit path verified by point sampling (21 px inside /
  23 px outside), no horizontal overflow at 860–1440, 200% page scale. Real AT/VoiceOver is recorded separately
  as a manual gate.
- The graph geometry authority document now records the 0.3.1 px decision and explicitly states that 200% root-font
  text scaling is not covered by the W0-2 page-scale evidence.
- Root `SHA256SUMS` now records the current local `0.3.1` candidate. The protected candidate/promotion workflow
