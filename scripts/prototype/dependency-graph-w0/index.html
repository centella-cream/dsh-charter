人工验证清单（机器测不了）

1. 真实浏览器文本缩放：Cmd/Ctrl + 连按到 200%，检查节点盒与文本同比放大、无溢出、边与标签仍对齐。
   （本页的"文本缩放"按钮是放大根字号的等价模拟，不能替代真实缩放：真实缩放还会影响 px 边框与 min-height:44px。）
2. forced colors（Windows 高对比度 / macOS 增强对比度）：状态是否仍可区分（边框线型 + 图标 + 文本，不靠色相）。
3. prefers-reduced-motion：开启系统"减少动态效果"后高亮过渡是否消失。
4. 屏幕阅读器（VoiceOver 或 NVDA）：进入图形区是否只播报一次组名；方向键移动是否播报
   "D2 · Build，前置 2/3，等待前置"；候选节点是否播报"候选提案 · … · 未进入执行序"；Esc 是否回到 skip 链接。
5. 触屏：节点与边的命中区是否 ≥44×44 CSS px（含不可见 hit 线）。
6. 200% 缩放 + 窄容器组合下，图形区是否仍可通过滚动/平移看到全部内容。
