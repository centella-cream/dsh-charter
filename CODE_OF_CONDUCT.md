# Code of Conduct

English | [中文](CODE_OF_CONDUCT.zh.md)

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussion focused on the code and the user problem. Harassment,
discrimination, and disclosure of private information are not acceptable.

Reports can be sent privately through the repository's security advisory channel. Maintainers may remove
comments, close threads, or block contributors who violate this code.
